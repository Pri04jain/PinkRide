🛠 Tech Stack

⚡
Node.js + Express
REST API backend. Lightweight, fast, great ecosystem for real-time apps. 59 endpoints across 9 modules.
🗄
Supabase (PostgreSQL)
Managed Postgres with RLS, real-time subscriptions, and storage. Free tier covers MVP. No DevOps overhead.
🔌
Socket.io
Real-time driver location updates every 5s, route deviation alerts, SOS broadcast — all via WebSocket rooms.
📱
Flutter (planned)
Single codebase for Android + iOS. Dart is fast to write. Strong Google Maps integration.
👁
AWS Rekognition
Face indexing + comparison for driver identity verification. Mock mode in dev — no AWS account needed to run locally.
💳
Razorpay
UPI payment orders + HMAC signature verification. Mock mode when keys not set. Cash payment also supported.

🧠 Key Architecture Decisions

📐
Haversine over PostGIS
PostGIS requires Docker + extensions. Haversine in pure JS gives the same distance accuracy for our scale. Easier to deploy, easier to debug.
💾
In-memory OTP store (no Redis)
Redis adds ops complexity for MVP. A simple Node.js Map with TTL handles thousands of concurrent OTPs. Swap to Upstash Redis when scaling horizontally.
🔒
DPDP Act 2025 compliance
Explicit consent before biometric capture. Only face embedding reference stored — never raw photos. Right-to-erasure endpoint deletes all face data on request.
🛡
Atomic ride acceptance
Driver accept uses .is('driver_id', null) filter — Supabase rejects the update if another driver already claimed it. No double-booking possible.
⚖️
Cancellation fine system
Passenger: ₹50 deducted from wallet. Driver: ₹150 fine + reliability score penalty (-0.3). Discourages last-minute cancellations without being punitive for genuine emergencies.
👩
Women-only safety design
Gender filter in matching engine. Male drivers allowed (hard to find female drivers in India). Driver photo verified via face recognition before every trip.
